# Simulasi Keputusan Bisnis: Kepala Cabang

Latihan mengambil keputusan sebagai kepala cabang sebuah bank fiktif ("Bank Sinar Nusantara"). Tidak ada merek asli.

## Ide dasarnya
Peserta menjalani lima babak. Di tiap babak ada situasi dan pilihan. Setiap pilihan punya akibat. Di akhir, peserta mendapat laporan tentang gaya keputusannya.

## Peran saya
- Menulis spesifikasi dan isi cerita lima babak (`spec.md`, `docs/review/`).
- Menentukan aturan penilaian dan kriteria lulus uji.
- Memeriksa isi tiap babak.
- Kode dibuat bersama Claude Code. Saya mengarahkan dan memeriksa.

## Cara melihat
Perlu Node.js. Di folder `app/`: `npm install`, lalu `npm run dev`. Uji: `npm test`.

## Batasan yang jujur
- Ini **mode contoh**. Penilaian memakai aturan sederhana, **belum memakai AI**.
- Hanya satu skenario (kepala cabang).
- Proyek latihan, belum produk jadi.
